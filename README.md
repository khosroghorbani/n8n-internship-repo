1) توضیح کوتاه UI:
فرم ورود ساده داخل یک کارت؛ شامل فیلد ایمیل، فیلد رمز با دکمهٔ نمایش/پنهان، دکمهٔ ورود، لینک «فراموشی رمز» و نمایش پیام‌های خطا/موفقیت با Alert. فرم به‌صورت کنترل‌شده با useState پیاده‌سازی شده و نمونهٔ درخواست سروری با تأخیر شبیه‌سازی می‌شود.

2) مسیر فایل ساخته‌شده:
src/components/LoginForm.tsx

3) تمام کامپوننت‌های DIG استفاده‌شده و دلیل انتخاب:
- card: برای قرار دادن فرم داخل یک ظرف منظم با سربرگ/بدنه/پاصفحه.
- text-field: برای ورودی ایمیل؛ فراهم‌کنندهٔ برچسب، placeholder و حالت کنترل‌شده.
- password-field: برای ورودی رمز با دکمهٔ نمایش/پنهان و قابلیت‌های UX مربوط به رمز.
- button: دکمهٔ ارسال با واریانت loading و fullWidth.
- alert: نمایش پیام‌های خطا یا موفقیت در بالای فرم.
- link: لینک «فراموشی رمز» با استایل دیگ.

4) تمام آیکون‌های DIGCHEH استفاده‌شده و دلیل انتخاب:
هیچ آیکون DIGCHEH جداگانه‌ای استفاده نشده — کامپوننت‌های دیگ (مثل PasswordField) آیکون‌های داخلی خود را دارند که با SVG داخلی‌شان مدیریت می‌شوند.

5) اگر آیکون استفاده نشده، صریحاً ذکر کن:
آیکون DIGCHEH استفاده نشده است؛ آیکون‌های داخلیِ کامپوننت‌های دیگ (PasswordField) در فایل‌ها موجودند و جایگزین نشده‌اند.

6) dependencyهای خارجی در صورت وجود:
هیچ dependency خارجی‌ای (بجز React و خودِ دیگ) در این فایل مورد نیاز نیست.

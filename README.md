1) توضیح کوتاه UI:
یک فرم ورود ساده با فیلد ایمیل و فیلد رمز عبور (دکمه نمایش/پنهان) و دکمه ارسال. فرم از react-hook-form برای مدیریت state و اعتبارسنجی پایه استفاده می‌کند.

2) مسیر فایل ساخته‌شده:
src/components/LoginForm.tsx

3) تمام کامپوننت‌های DIG استفاده‌شده و دلیل انتخاب:
- form: برای اتصال امن و سادهٔ react-hook-form به اجزای فرم و مدیریت خطاهای سمت سرور/aria.
- text-field: برای فیلد ایمیل با برچسب، توضیح و مدیریت حالت‌های invalid به‌صورت آماده.
- password-field: برای فیلد رمز عبور با دکمهٔ نمایش/پنهان (revealToggle) — مناسب فرم ورود که نیاز به نمایش رمز دارد.
- button: برای دکمهٔ ارسال با واریانت و تنظیم fullWidth.

4) تمام آیکون‌های DIGCHEH استفاده‌شده و دلیل انتخاب:
هیچ آیکون DIGCHEH مستقلی درخواست یا استفاده نشده — آیکون‌های داخلی کامپوننت‌ها (مانند چشم در PasswordField) داخلیِ دیگ هستند و در این فهرست لحاظ نشده‌اند.

5) اگر آیکون استفاده نشده، صریحاً ذکر کن:
آیکون خارجی استفاده نشده است.

6) dependencyهای خارجی در صورت وجود:
- react-hook-form (برای مدیریت فرم)

# Simple Python Calculator

A small calculator project implementing addition, subtraction, multiplication, and division.

## Requirements

- Python 3.8 or newer

No third-party dependencies are required.

## Run the program

From the project root, run:

```bash
python calculator.py
```

The command prints a smoke demonstration of all four operations.

## Run the tests

Run the complete unittest suite with:

```bash
python -m unittest discover -s tests -v
```

The tests cover successful arithmetic operations, division by zero, and invalid operands.

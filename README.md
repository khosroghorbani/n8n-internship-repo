# Python Calculator

یک ماشین‌حساب ساده با Python که عملیات جمع، تفریق، ضرب و تقسیم را ارائه می‌دهد.

## اجرا

برای اجرای برنامه نمایشی:

```bash
python calculator.py
```

## اجرای تست‌ها

تست‌ها با کتابخانه استاندارد `unittest` نوشته شده‌اند و با دستور زیر اجرا می‌شوند:

```bash
python -m unittest discover -s tests -v
```

این پروژه برای هر چهار عملیات، تقسیم بر صفر، ورودی‌های نامعتبر و رد کردن مقدارهای بولی تست دارد.

# Python Calculator

این پروژه یک ماشین‌حساب سادهٔ پایتون است و عملیات جمع، تفریق، ضرب و تقسیم را ارائه می‌دهد.

## اجرا

```bash
python calculator.py
```

## اجرای تست‌ها

```bash
python -m unittest discover -s tests -v
```

توابع ماشین‌حساب ورودی‌های عددی واقعی را می‌پذیرند، مقدارهای بولی را به‌عنوان عدد قبول نمی‌کنند و تقسیم بر صفر با `ZeroDivisionError` مدیریت می‌شود.

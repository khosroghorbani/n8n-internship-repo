1) توضیح کوتاه UI:
یک فرم ورود سادهٔ کارت‌محور با دو فیلد: ایمیل و رمز عبور، اعتبارسنجی پایهٔ سمت کلاینت، نمایش پیام خطا و دکمهٔ ارسال با وضعیت loading.

2) مسیر فایل ساخته‌شده:
src/components/LoginForm.tsx

3) تمام کامپوننت‌های DIG استفاده‌شده و دلیل انتخاب:
- form: برای اتصال و مدیریت فرم با react-hook-form و استفاده از FormProvider و اجزای مرتبط (FormField, FormItem, ...).
- input: فیلد ورودی متن برای ایمیل (پشتیبانی از placeholder، clearable و رفتار استاندارد ورودی).
- password-field: فیلد رمز عبور با دکمهٔ نمایش/پنهان و مدیریت مقدار (از API داخلی کامپوننت استفاده شد).
- button: دکمهٔ ارسال با واریانت‌های loading و fullWidth.
- card: ظرف بصری برای فرم (سرصفحه/بدنه/پاصفحه) تا فرم ظاهر متمرکزی داشته باشد.

4) آیکون‌های DIGCHEH استفاده‌شده و دلیل انتخاب:
هیچ آیکون DIGCHEH مستقلی در این فایل استفاده نشده — آیکون‌های داخلیِ کامپوننت‌هایی مانند PasswordField داخلی و مستقل هستند و نیازی به صدازدن DIGCHEH نبود.

5) اگر آیکون استفاده نشده، صریحاً ذکر شد: آیکون خارجی استفاده نشده.

6) dependencyهای خارجی در صورت وجود:
- react-hook-form: برای مدیریت فرم و اعتبارسنجی و اتصال به کامپوننت‌های Form/Controller دیگ.
